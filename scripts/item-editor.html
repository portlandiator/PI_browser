Edit a catalog item

Correct one item’s metadata, original text or English translation, or delete an item. Each saved edit waits in Downloads/subject-edits.json on this computer, alongside any subject decisions; nothing else changes. When you are ready, run Publish-Editorial-Decisions.cmd (maintenance folder): it publishes every pending edit, with any exported subject decisions, as one pull request on GitHub, and then writes the edits to the source folders here with backups.

Use this editor for existing IDs. To add or rename a catalog item, use Update-Collection.cmd. The public website remains read-only.

Delete an item from the catalog

Removes the item whose ID is in “Exact catalog ID” from the website, together with every quotation taken from it in the subject compilations and every study-guide reading built on those quotations. The volume PDFs are not changed. Preview first; the deletion is then recorded as a pending edit and happens when you publish.
