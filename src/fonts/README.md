# Locally hosted typefaces

EB Garamond (regular and italic, variable weights 400–800) and Scheherazade New
(regular and bold) are distributed under the SIL Open Font License. Their
unmodified font files and licenses were downloaded on 2026-09-18 from:

- https://github.com/google/fonts/tree/main/ofl/ebgaramond
- https://github.com/google/fonts/tree/main/ofl/scheherazadenew

The site serves these files itself; readers do not contact an external font service.
