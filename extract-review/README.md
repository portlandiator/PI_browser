# Extract review

Each CSV includes every retained selection from that source without an accepted paragraph mapping, including outside-author quotations. Fill in **Assign ID**, **Assign paragraph** (one-based, as in the Catalog reader), and **Notes**. Leave outside-catalogue quotations blank. Candidate scores are lexical coverage, not probabilities. Original files are unchanged. Duplicates removed from these queues remain recorded in input-report.json and the retained selection provenance.

For exact highlight selection, use the website’s Passage review utility and export its decisions. CSV assignments can be returned for incorporation with paragraph/range validation.
